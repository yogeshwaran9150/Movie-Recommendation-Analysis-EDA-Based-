# 🎬 Movie Recommendation Analysis (EDA-Based)

## 📌 Project Overview
This project focuses on analyzing movie rating data to understand user preferences, popular movies, and genre trends using Exploratory Data Analysis (EDA). The analysis is performed without building any machine learning models and is purely based on data exploration and visualization techniques.

The main objective of this project is to identify meaningful patterns in movie ratings and user behavior that can support the understanding of recommendation systems.

---

## 📂 Dataset Description
The dataset used in this project consists of:
- **Movies Dataset**: Contains movie titles and genres  
- **Ratings Dataset**: Contains user ratings for movies  

These datasets are widely used for recommendation system analysis and exploratory studies.

---

---

## 🔍 Key Analysis Performed
- Analysis of rating distribution  
- Identification of most popular and most rated movies  
- Genre-wise movie analysis  
- Average rating comparison across genres  
- User rating behavior analysis  

---

## 📊 Visualizations
- Bar charts for top-rated and most-rated movies  
- Histograms for rating distribution  
- Pie charts for genre distribution  
- Heatmaps for correlation analysis
